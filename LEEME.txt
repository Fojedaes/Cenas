CENAS DE LA SEMANA - PWA

Sube a GitHub (en la raíz del repositorio) index.html, manifest.webmanifest, sw.js y la carpeta icons.
NO subas a GitHub el archivo Codigo.gs: contiene la clave de vuestro plan compartido.

Para publicar una versión nueva más adelante: sustituye index.html y, en sw.js, cambia VERSION ('cenas-v3' -> 'cenas-v4').
